# weatherapi

## Descrição:

Este é um projeto front-end de consulta meteorológica integrado à API do Open Weather Map. Ele usa um servidor back-end para seu funcionamento (o servidor está em um plano gratuito, por isso a primeira busca pode demorar de 30 segundos a 1 minuto para carregar). Foram utilizadas as seguintes tecnologias: `HTML5` `CSS3` `JavaScript (ES6+)` `Node.js` `Express.js` `CORS` `Dotenv` `OpenWeatherMap API` `Fetch API` `Render`.

## Como usar:

No campo de texto, digite o Estado ou cidade que desejar e o site retornará as informações de temperatura e de vento desse local.
